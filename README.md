# Atrium

Local-first personal command center. Times and quotes are Asia/Manila. Data stays in the browser (`atrium.v1`).

## Use

- Command bar: type to search the desk — `BDO`, `ayala`, `note: buy rice`, `Lunch Friday 1pm` (`⌘K` on Mac, `Ctrl+K` elsewhere)
- Dashboard: drag a card grip to rearrange; Reset layout restores the factory order
- Calendar: Month / Week / Day / Agenda, plus all-day events
- Finance: Markets first (official PSEi 30, Yahoo screener with PE/cap filters, sparks, research PDF) and Books (cash, bank, wallet, card). Add any ticker from the plus button. Stock tape in Options: Auto (phisix + Yahoo) or Yahoo-only. Google Finance, MSN Money, and Investa are not public feeds.
- Quotes: optional module. Topic chips (life, funny, love, wisdom, success, motivational, nature). Live public lines, shuffled on Random — desk copies only if the feed is empty
- Notes: board or list, palette icon for color, freehand pencil, resize any corner (handles hide until hover), drag from the top bar, pin to the desktop
- News: tagged briefing with search; every RSS source starts off — pick what you want in Feeds
- Sidebar: collapse above Options; the tagline under them is yours to edit. Toggle modules in Options.
- Profile: name and city start blank — pin a place in Options for weather
- Floating desk: pin notes and widgets over any screen. Drag the grip in the title bar; any corner resizes.
