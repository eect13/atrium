# Atrium

Local-first personal command center for calendar, notes, finance, and news. Times and quotes are Asia/Manila. Data stays in the browser.

## Use

- Command bar: `Lunch Friday 1pm`, `note: buy rice`, `spend 500 Grab`
- Calendar: Month / Week / Day / Agenda, plus all-day events
- Finance: cash on hand, watchlist, FX converter, PSE tape
- News: mixed briefing (BBC, Verge, Rappler, Bilyonaryo, X)
- Floating desk: pin notes and widgets over any screen

Created with Grok.
