# Atrium

Local-first personal command center. Times and quotes are Asia/Manila. Data stays in the browser (`atrium.v1`).

## Use

- Command bar: `Lunch Friday 1pm`, `note: buy rice`, `spend 500 Grab`
- Calendar: Month / Week / Day / Agenda, plus all-day events
- Finance: Markets first (official PSEi 30, sparks, research PDF, related news) and Books (cash, bank, wallet, card)
- Quotes: BrainyQuote library — a new roll each session, Popular, or search by person
- News: tagged briefing; paste a site or RSS URL and Atrium finds the feed
- Sidebar: collapse to icons; scrollbars stay hidden until you hover
- Floating desk: pin notes and widgets over any screen
